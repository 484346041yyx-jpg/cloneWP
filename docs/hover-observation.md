# 通用悬停取证

新来源采集使用 `src/replica-v2/collect.browser.js`。采集器读取当前可访问且当前媒体条件生效的 CSS 规则，把可见元素匹配到的 `:hover` 规则登记为 `kind: hover, status: declared`。这只是待观察清单，不能当作已验证效果。被浏览器跨域限制而无法读取的样式表会留下 `hover-stylesheet-unreadable` 缺口；CSSOM 也无法穷尽 JavaScript 鼠标监听器。观察员还须检查明显的按钮、导航、图片卡片等交互区域。

对每个声明的触发元素，使用浏览器适配器**真实鼠标悬停**，依次采集默认、悬停、移开恢复三个状态及各自截图。每次在同一页面调用只读 `collectHoverStateV2`，传入来源 URL、来源包中的唯一 `triggerSelector`、受影响元素的唯一选择器、对应 `stage` 和实际截图 SHA-256。采集器会核实真实 `:hover` 状态，记录元素及伪元素的计算样式、尺寸、媒体来源和时间。没有原生 hover 能力时标记能力缺口并停止该项，不能用拖拽、右键或合成事件冒充。

把三态与截图引用写成 `source-hover-review`，放入 `sourceEvidence.additionalEvidence`。准备入口会按当前新采集的 CSS 悬停事实逐项核对触发节点、顺序、指针状态、截图散列和完整覆盖；任何缺项在认证目标站前失败。生成阶段按实测差异选择原生悬停设置或任务作用域 CSS；最终在来源与目标的相同状态核对颜色、下划线、位移、缩放、伪元素、媒体与恢复状态。旧来源包没有这类事实，不自动迁移或改变旧任务合同。
